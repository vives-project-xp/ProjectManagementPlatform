# Integrate Trello instead of building our own task board

Projects get a real Trello board created automatically through the Trello API, as the project brief asks. We deliberately do not build our own task system (Kanban, list, Gantt, calendar and workload views, subtasks, dependencies, recurring tasks): that would be a Jira/ClickUp-sized product on its own and would push the MVP and the higher-priority features (Top 3, GitHub repositories) far out.
